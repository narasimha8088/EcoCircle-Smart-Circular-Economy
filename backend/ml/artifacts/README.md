# ML Model Artifacts

This directory stores trained model pickle files for Phase 2 models.

| File | Model | Generated by |
|------|-------|-------------|
| `carbon_model.pkl` | Carbon Footprint Estimator (M5) | `train/train_carbon.py` |
| `resale_model.pkl` | Resale Valuation Model (M6) | `train/train_resale.py` |
| `eco_trend_model.pkl` | Eco-Score Trend Predictor (M7) | `train/train_eco_trend.py` |

Run `python ml/train/train_carbon.py` etc. from the `backend/` directory to generate these files.
They are excluded from Git (see `.gitignore`) due to binary size.
